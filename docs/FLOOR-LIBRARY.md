# Floor library map

Games are **mounted**, never copied. Config: `~/.config/nyxus/arcade-library.conf`
(sshfs `msi:/home/cosmic/GDrive/Games/ROMs` → `~/Games/roms`).

## Arcade cabinets (layout)

| Cabinet | Folder | Core |
|---|---|---|
| NES | `NES` / `nes` | nestopia |
| SNES | `SNES` / `snes` | snes9x |
| Genesis | `Sega Genesis` | genesis_plus_gx |
| N64 | `Nintendo 64` | mupen64plus_next |
| PlayStation | `PlayStation` | pcsx_rearmed |
| Arcade | `Arcade (MAME)` | (mame) |
| GBA | `Game Boy Advance` | mgba |
| Atari 2600 | `Atari 2600` | stella when present |

Also on the mount (not on the first row): GB, GBC, Master System, Game Gear, PS2, 32X, TurboGrafx-16, Jaguar, Lynx, 7800.

System logos: `quickshell/floor-art/` (from the Blast theme already on this machine).

## Movies / shows

Official watch-only. Midnight Society / ToonCabinet kiosk. No yt-dlp of copyrighted shows.
Poster wall uses original Nyxus cards (STARLIGHT, MAGMA, MIDNIGHT, SHOWS, CONTINUE, FEATURE) — not studio one-sheets.

Game titles on cabinets will come from a **scan** of the mount (filenames), not from a download pack.
