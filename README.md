# Nyxus Suxyn

Daily-driver desktop for this Alienware: Hyprland + Quickshell.

This repo is **this build only**. It is not Nyxus-Core, not MSI, and not personal apps.

## Layout

| Path | What |
|---|---|
| `quickshell/` | Bar, Start, lock, flyout, Settings, widgets, Nyxus apps (Notes, Media, …) |
| `hypr/` | Hyprland, hyprlock, hypridle, walls |
| `gtk-3.0/` `gtk-4.0/` | Font / rendering |
| `ghostty/` | Terminal font |
| `tools/` | GTK-login pin and snapshot repair (boot greeter is not in this repo) |

## Not in this repo

Personal apps, local AI, security-stack tools, ISO builder, and other machines' trees.
