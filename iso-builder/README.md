# Nyxus Suxyn ISO baker

This is a **new** Suxyn image for **anyone's PC** — different systems,
different hardware. It is not a clone of the Alienware that bakes it,
and it is not Nyxus-Core. Do not copy Core's builder.

Output name: `nyxus-suxyn-YYYY.MM.DD-x86_64.iso`  
Volume label: `NYXUS_SUXYN`  
Install dir: `suxyn`

## Any-machine rules (hard)

The stick must boot unknown hardware. This laptop is only the *build host*.

**Live ISO (the stick)**

- Stock Arch `linux`. Do not strip modules. Do not `localmodconfig`.
- Full `linux-firmware` (Intel / NVIDIA / AMD / Atheros / Realtek / …).
  Do not cut blobs because this chassis does not use them.
- Live initramfs MODULES: common GPU set
  (`i915 amdgpu nvidia nvidia_modeset nvidia_drm`) **or** empty without
  autodetect. **Never** ship this machine's
  `/etc/mkinitcpio.conf.d/20-nyxus-hardware.conf` (`amdgpu` + NVIDIA only)
  as the image default. That file is install-time, generated by
  `nyxus-hwdetect` on the **target**.
- ISO Hyprland monitor line: `monitor = , preferred, auto, 1`.
  Do **not** bake `eDP-1, 1920x1200@165`. Copilot's fallback is correct
  for the stick, wrong to apply blindly on the owner's laptop.
- Do **not** ship NVIDIA-only env (`LIBVA_DRIVER_NAME`, `__GLX_VENDOR`)
  as the only path. `nyxus-session-start` detects; `nyxus-hwcaps` /
  firstboot set it on the installed system.
- Do **not** bake user `gowski`, this hostname, Wi-Fi secrets, weather
  lat/lon `42.511/-83.616`, or personal Brain/notes. Live user is `nyx`.
  Calamares creates the real user.
- First boot on disk runs `/etc/nyxus-firstboot.d/03-hardware-initramfs.sh`
  (no-op on live: `/run/archiso` is present).

**Installed system (after Calamares)**

- `nyxus-hwdetect` writes `MODULES` from **that** machine's PCI bus.
- `nyxus-hwcaps` drives Settings ▸ Hardware (hide fans if none).
- Shell from this repo (`quickshell/` + `hypr/`) with generic monitors.
  The owner machine keeps its 165 Hz line locally, not in the ISO tree.

`build-iso.sh` encodes the same rules as comments and as fail-the-bake
gates. The on-image copy is `airootfs/etc/nyxus/HARDWARE-RULES`.

## Product

- Kernel: stock `linux` only (no Kage-Ryu, no Aether until proven).
- Packages: `packages.x86_64` — daily-driver list. Intel + AMD + NVIDIA
  stacks all ship so an unknown PC has drivers.
- Installer branding: `../installer/calamares/branding/nyxus/`
- Shell: `../quickshell/` + `../hypr/` staged at bake; monitors forced generic.

Do **not** upload the ISO to GitHub (release cap 2 GB; this image is ~8 GB).

## Bake

`mkarchiso` may not be installed yet. Install it, then bake as root:

```bash
sudo pacman -S archiso
sudo iso-builder/build-iso.sh
```

Work directory is `/tmp/suxyn-iso`; the ISO lands in `iso-builder/out/`.

## Profile

| Path | Role |
|---|---|
| `build-iso.sh` | Baker + hard-rule gates |
| `profile/profiledef.sh` | `iso_name=nyxus-suxyn`, `install_dir=suxyn` |
| `packages.x86_64` | Image package list (full `linux-firmware`) |
| `profile/airootfs/etc/mkinitcpio.conf.d/archiso.conf` | Live MODULES = common GPU set, **no autodetect** |
| `profile/airootfs/etc/mkinitcpio.conf` | Installed fallback MODULES (same common set) |
| `profile/airootfs/usr/local/bin/nyxus-hwdetect` | Writes `20-nyxus-hardware.conf` on the **target** |
| `profile/airootfs/etc/nyxus-firstboot.d/03-hardware-initramfs.sh` | First-boot rebuild if Calamares did not |
| `profile/airootfs/etc/calamares/` | Installer; `shellprocess@initramfs` runs hwdetect then `mkinitcpio -P` |
| `profile/airootfs/etc/skel/.config/hypr/nyxus-monitors.conf` | `monitor = , preferred, auto, 1` |
| `profile/airootfs/etc/hostname` | `suxyn` (never the baker's hostname) |

`20-nyxus-hardware.conf` is **not** in this tree on purpose.
