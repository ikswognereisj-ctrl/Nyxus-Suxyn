# Installer branding

Calamares theme for Nyxus Suxyn. Void ground, ice type, magma for the current step and the Install button.

Copy onto an ISO airootfs as:

```
etc/calamares/branding/nyxus/
```

This tree is not applied to a running system without root. The live stick still uses `/etc/calamares` until the next bake.
